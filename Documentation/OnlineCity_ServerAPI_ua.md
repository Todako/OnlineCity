### API сервера
Сервер підтримує HTTP API для **POST-запитів** у форматі **JSON (UTF-8)** або `multipart/form-data`.
Запити надсилаються на той самий порт, що й ігрове підключення. На одне TCP-з’єднання дозволений лише **один запит**, після відповіді з’єднання закривається.

**Приклад JSON-запиту:**
```json
{ "Q": "PlayerStat" }
```

**Відповідь:**
```json
{
  "OnlineCount": 1,
  "PlayerCount": 674,
  "Onlines": ["TheCrazeMan"]
}
```

Доступні API-команди описані нижче та в `OnlineCityAPIModel.cs`. Для C# можна використовувати `OnlineCityAPIClient.cs`.

**Перевірка через Telnet**
Для швидкої перевірки підключення можна використати `telnet`:
```text
o 127.0.0.1 19019

POST / HTTP/1.1

{Q:"s"}
```

Приклад відповіді:
```text
HTTP/1.0 200 OK
Content-Type: application/json; charset=utf-8
Connection: close

{"OnlineCount":0,"PlayerCount":2,"Onlines":[]}
```

**Multipart-запити та зображення**
Для `multipart/form-data` можна використати готовий приклад `Documentation\test.html`. Відкрийте його у браузері та вкажіть потрібні параметри.
API також підтримує завантаження та отримання зображень. Для цього використовується `multipart/form-data`, а в полі `N` вказується спеціальне ім’я:
* `pl_Нік` — аватар гравця.
* `cs_Нік@serverId` — скріншот колонії. `serverId` можна отримати через `Q:"a"` або `Q:"p"` у полі `BaseServerIds`.

Для деяких команд потрібен параметр `Key`. Він має збігатися з `SecretKey` у налаштуваннях сервера.

**Додаткові команди**
* `cc` — виконує консольну команду. Символ команди передається в `N`, ключ — у `Key`.
* `cp` — надсилає текст у ігровий чат. Текст передається в `N`, ключ — у `Key`.
* `BlockKey` — повертає вміст `blockkey.txt`.
* `PlayerStat` — повертає статистику гравців, аналогічну команді `S` у консолі сервера.

**Підтвердження реєстрації**
Для ручного підтвердження гравців увімкніть у налаштуваннях:
* `PlayerNeedApprove`
* `PlayerNeedApproveInDiscord`

Наразі підтвердження доступне лише через Discord.

Після реєстрації запит `Q:"s"` із `Key` повертає список гравців для підтвердження у полі `NeedApprove` у форматі `Нік*Discord`.
Для підтвердження використовуйте `PlayerApprove` (`pa`):
* `Login` — логіни підтверджених гравців через `*`;
* `N` — логіни відхилених гравців. Вони будуть видалені, а їхні логіни знову стануть доступними для реєстрації.

### API-команди
| `Q`          | Призначення                                                                                                                                                                      | Параметри                                     |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------- |
| `s`          | Загальна інформація про сервер: кількість гравців онлайн та загальна кількість зареєстрованих. Також повертає список гравців, які очікують підтвердження.                        | `Key` — для отримання `NeedApprove`           |
| `p`          | Інформація про конкретного гравця.                                                                                                                                               | `Login` — логін гравця                        |
| `a`          | Інформація про всіх зареєстрованих гравців.                                                                                                                                      | —                                             |
| `PlayerStat` | Повний звіт про гравців, аналогічний команді `S` у консолі сервера.                                                                                                              | `Key`                                         |
| `BlockKey`   | Повертає вміст файлу `blockkey.txt` із сервера.                                                                                                                                  | `Key`                                         |
| `cc`         | Виконує однолітерну команду консолі сервера.                                                                                                                                     | `N` — команда, `Key`                          |
| `cp`         | Надсилає текст у загальний ігровий чат, аналогічно `command.txt`.                                                                                                                | `N` — текст, `Key`                            |
| `pa`         | Підтверджує або відхиляє реєстрацію гравців.                                                                                                                                     | `Login` — підтвердити, `N` — відхилити, `Key` |
| `li`         | Отримує зображення із сервера.                                                                                                                                                   | `N` — ім'я зображення, `Key`                  |
| `si`         | Зберігає зображення на сервері.                                                                                                                                                  | `N` — ім'я, `Data` — дані зображення, `Key`   |

### Параметри запиту
| Параметр | Тип      | Опис                                                                                                    |
| -------- | -------- | ------------------------------------------------------------------------------------------------------- |
| `Q`      | `string` | Код API-команди. Регістр не має значення.                                                               |
| `T`      | `int`    | Додатковий числовий параметр У `APIRequest`                                                             |
| `Login`  | `string` | Логін гравця. Використовується для `p` та `pa`. Для `pa` може містити кілька логінів через `*`.         |
| `N`      | `string` | Основний параметр команди. Використовується для команд `cc`, `cp`, `pa`, `li` та `si`.                  |
| `Key`    | `string` | Ключ доступу до захищених команд.                                                                       |
| `Data`   | `byte[]` | Дані зображення для команди `si`.                                                                       |

### Дані відповіді
#### `s` — статус сервера
Повертає `APIResponseStatus`:
| Поле          | Тип            | Опис                                                         |
| ------------- | -------------- | ------------------------------------------------------------ |
| `OnlineCount` | `int`          | Кількість гравців онлайн.                                    |
| `PlayerCount` | `int`          | Загальна кількість зареєстрованих гравців.                   |
| `Onlines`     | `List<string>` | Логіни гравців онлайн.                                       |
| `NeedApprove` | `List<string>` | Гравці, які очікують підтвердження. Формат: `логін*Discord`. |

#### `p` та `a` — інформація про гравців
Повертають `APIResponsePlayers` зі списком `Players`:
| Поле               | Тип        | Опис                                         |
| ------------------ | ---------- | -------------------------------------------- |
| `Login`            | `string`   | Логін гравця.                                |
| `DiscordUserName`  | `string`   | Ім'я користувача в Discord.                  |
| `LastOnlineTime`   | `DateTime` | Час останньої активності за UTC (Гринвічем). |
| `Days`             | `long`     | Кількість ігрових днів. `Days / 60` ≈ роки.  |
| `BaseCount`        | `int`      | Кількість поселень гравця.                   |
| `CaravanCount`     | `int`      | Кількість караванів гравця.                  |
| `MarketValueTotal` | `float`    | Загальна ринкова вартість майна.             |
| `BaseServerIds`    | `string`   | ID поселень, розділені комою.                |

### Зображення
Для `li` та `si` параметр `N` містить спеціальне ім'я:
* `pl_Нік` — аватар гравця.
* `cs_Нік@serverId` — скріншот колонії.

`serverId` можна отримати з `BaseServerIds` через `a` або `p`.

### Помилки
При помилці API повертає `APIResponseError`:
| Поле    | Тип      | Опис          |
| ------- | -------- | ------------- |
| `Error` | `string` | Опис помилки. |
