### API сервера
Сервер підтримує HTTP API для **POST-запитів** у форматі **JSON (UTF-8)** або `multipart/form-data`.
Запити надсилаються на той самий порт, що й ігрове підключення. Одне TCP-з’єднання обробляє лише один запит, після чого закривається.

Для C# можна використовувати `OnlineCityAPIClient.cs`. Повний список команд описаний нижче та в `OnlineCityAPIModel.cs`.

**Приклад запиту:**
```json
{ "Q": "s" }
```

### Команди API
| `Q`          | Опис                                                                                               | Параметри                 |
| ------------ | -------------------------------------------------------------------------------------------------- | ------------------------- |
| `s`          | Статус сервера: гравці онлайн, загальна кількість гравців та список тих, хто очікує підтвердження. | `Key` — для `NeedApprove` |
| `p`          | Інформація про конкретного гравця.                                                                 | `Login`                   |
| `a`          | Інформація про всіх зареєстрованих гравців.                                                        | —                         |
| `PlayerStat` | Повний звіт про гравців, аналог команди `S` у консолі.                                             | `Key`                     |
| `BlockKey`   | Повертає вміст `blockkey.txt`.                                                                     | `Key`                     |
| `cc`         | Виконує однолітерну команду консолі сервера.                                                       | `N`, `Key`                |
| `cp`         | Надсилає повідомлення в загальний ігровий чат.                                                     | `N`, `Key`                |
| `pa`         | Підтверджує або відхиляє реєстрацію гравців.                                                       | `Login`, `N`, `Key`       |
| `li`         | Отримує зображення із сервера.                                                                     | `N`, `Key`                |
| `si`         | Зберігає зображення на сервері.                                                                    | `N`, `Data`, `Key`        |

### Параметри запиту
| Параметр | Опис                                                                                          |
| -------- | --------------------------------------------------------------------------------------------- |
| `Q`      | Код команди API. Регістр не має значення.                                                     |
| `Login`  | Логін гравця. Для `pa` можна вказати кілька логінів через `*`.                                |
| `N`      | Додатковий параметр команди: команда консолі, текст повідомлення, логіни або ім’я зображення. |
| `Key`    | Ключ доступу для захищених команд. Має збігатися з `SecretKey` сервера.                       |
| `Data`   | Дані зображення для команди `si`.                                                             |
| `T`      | Додатковий числовий параметр. Його призначення визначається обробником API.                   |

### Відповідь `s`
Повертає:
| Поле          | Опис                                                         |
| ------------- | ------------------------------------------------------------ |
| `OnlineCount` | Кількість гравців онлайн.                                    |
| `PlayerCount` | Загальна кількість зареєстрованих гравців.                   |
| `Onlines`     | Список логінів гравців онлайн.                               |
| `NeedApprove` | Гравці, які очікують підтвердження. Формат: `логін*Discord`. |

### Відповідь `p` та `a`
Повертають список `Players` з інформацією про гравців:
| Поле               | Опис                                        |
| ------------------ | ------------------------------------------- |
| `Login`            | Логін гравця.                               |
| `DiscordUserName`  | Ім’я користувача в Discord.                 |
| `LastOnlineTime`   | Час останньої активності за UTC.            |
| `Days`             | Кількість ігрових днів. `Days / 60` ≈ роки. |
| `BaseCount`        | Кількість поселень.                         |
| `CaravanCount`     | Кількість караванів.                        |
| `MarketValueTotal` | Загальна ринкова вартість майна.            |
| `BaseServerIds`    | ID поселень, розділені комою.               |

### Зображення
Команди `li` та `si` використовують `multipart/form-data`.
У `N` вказується ім’я зображення:
* `pl_Нік` — аватар гравця.
* `cs_Нік@serverId` — скріншот колонії.

`serverId` можна отримати через `a` або `p` у полі `BaseServerIds`.
Готовий приклад `multipart/form-data` знаходиться в `Documentation\test.html`.

### Підтвердження реєстрації
Для ручного підтвердження гравців увімкніть:
* `PlayerNeedApprove`
* `PlayerNeedApproveInDiscord`

Наразі підтвердження доступне лише через Discord.

Команда `s` з параметром `Key` повертає список `NeedApprove` у форматі:
```text
Нік*Discord
```

Для підтвердження використовується `pa`:
* `Login` — логіни підтверджених гравців через `*`;
* `N` — логіни відхилених гравців через `*`.

Відхилені гравці видаляються, після чого їхні логіни знову можна реєструвати.

### Помилки
У разі помилки API повертає:
```json
{
  "Error": "Опис помилки"
}
```

### Перевірка через Telnet
Для швидкої перевірки API можна використати `telnet`:
```text
o 127.0.0.1 19019

POST / HTTP/1.1

{Q:"s"}
```

Приклад відповіді:
```text
HTTP/1.0 200 OK
Content-Type: application/json; charset=utf-8
Connection: close

{"OnlineCount":0,"PlayerCount":2,"Onlines":[]}
```
